# task/

A path here is named from `task/` when it is the plugin's own file; `docs/` and `.github/` paths are the repository's.

A sixth plugin in this marketplace (versioned on its own: `scripts/bump-version.sh --plugin task`), the `task` command: the agents' one command for tracked work, which today works tickets on a repository's GitHub board. Design, decisions and the milestones still to come (the relabel, claims, the skill, sminos's calls): `docs/doperpowers/specs/2026-11-24-ticket-board-design.md`; what follows is how the code meets it.

- `bin/task` runs `cli/main.py`, Python 3.9 and the standard library only; it imports nothing of doperpowers or sminos.
- `cli/config.py` decides which board a command works: the repository of the clone's designated remote (`git config task.remote`, else `origin`), read from its URL, configured by `.doperpowers/board.json` on `refs/remotes/<remote>/HEAD` (that exact ref, `git show-ref --verify`) as last fetched, never the working tree's copy; `--repo owner/name` reads that repository's default branch on GitHub instead. A board whose file is missing, names another repository or says a binding other than `task` is refused before any call to GitHub. It makes no fetch.
- `cli/github.py` is all GitHub access: `gh api --hostname github.com` with the repository in every call (never `gh issue`, never `{owner}`, never a host `GH_HOST` names), GraphQL operations named `Task…`, label writes as single adds and removes. A comment's id is read as `fullDatabaseId`: comment ids pass 2^31, beyond GraphQL's `Int`.
- `cli/record.py` is the record block (`task-record`, the body's last fenced block) and the body digest; `cli/board.py` the label vocabulary and a ticket as the reading verbs print it, trust and takeability included; `cli/lint.py` the lint; `cli/sminos_client.py` what `task` asks sminos (`TASK_SMINOS`, then `PATH`, then the marketplace clone; 30 s a call; anything but a well-formed answer is no answer); `cli/verbs.py` the verbs.
- `board.CROSS_REPOSITORY_BLOCKED_BY` says whether `--blocked-by owner/name#n` is taken: `live.sh edge` found GitHub keeps such an edge (2026-11-27). Were that to change, setting it False makes the CLI refuse such a blocker and say the wait is prose.
- A body file is prose: one that opens a `task-record` or `task-claim` fence is refused, so a record's keys are written only by their flags and verbs, and a claim record only by the claim verbs. Between prose and block the CLI writes exactly a blank line (`record.SEPARATOR`) and takes exactly that away with the block's last key, so a change of the record alone leaves the prose's bytes as they were.
- `cli/migrate.py` is the one-time relabel (`migrate plan`, `migrate apply`; D6, §8), `cli/legacy.py` what the old board left in a body: the trailing `board:meta` block, found as the old scripts' `meta_match` finds it (ported, not imported) and rewritten as visible lines, a pinned `plan:` becoming the record's `spec:`; and the retired service's mirror header, matched by its exact lines with the service's address matched by form, so no host is written here. `plan` resolves only a repository (no board file is read) and writes its file mode 0600, refusing a path inside any git work tree (default: `$TASK_HOME/plans/`); decision rows carry a `question` beside §8's keys. `apply` reads each row's issue again and takes up only a state the write order leaves (`_on_the_path`); a failed write stops its row, not the apply, which then exits 1, and its summary counts the writes it made (`writes: 0` on a rerun).
- Nothing reads who holds a ticket yet: `holder` is null and `claimed` is never read.

Tests: `tests/run.sh` is the `task` gate, the CLI run as a process against `tests/standin/gh` (a `gh api` over a JSON state file, every call logged) and `tests/standin/sminos`, fixtures in `tests/harness.py`, every name invented. `tests/live.sh <case>` (`fork`, `edge`, `migrate`, whose Python steps are `tests/live_migrate.py`) runs against real GitHub, on the private scratch repositories `TASK_LIVE_REPO` and `TASK_LIVE_REPO2` name, and is never part of the gate.
