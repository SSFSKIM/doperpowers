# Board service tickets on GitHub

Until 2026-11-19 this repository's board lived on an external board service, whose ticket numbers (1–187) are not this repository's GitHub issue numbers. Older code, docs and commits name those tickets as `board #<n>`, `board ticket <n>` or `dp#<n>`. The service is retired; its open tickets moved to GitHub issues on 2026-11-19, and this table maps each one to its issue.

Tickets 114, 117, 173 and 184 were kept private and are not on GitHub. Tickets 62, 75, 112, 155 and 170 were not moved: their work had landed or their premise no longer held. Tickets that were closed on the service before the move are not here.
