# hooks/ — the doperpowers plugin's hooks

Bare file names and `mods/` are this directory's; other paths are the repository's. `hooks.json` wires them; the function hooks are in `mods/` (map in `mods/CLAUDE.md`), loaded only under `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1`. The project family's shell hooks, the ask tool, the bridge and the session's address are the sminos plugin's (`sminos/`).

- `kairos.sh` (`SessionStart`) injects the `kairos` skill's body at startup and after every compaction, for a session in the mode only: launched with `KAIROS=1`, or switched on by `/kairos`, which `kairos-toggle.sh` (`UserPromptExpansion`) records as a flag file under `~/.claude/kairos/<session-id>`; `/kairos off` removes it.
- `to-human-stream.sh` (`MessageDisplay`) draws the `<message>` mark's labels while a message streams, since the engine mounts an `AssistantMessage` only once a block is whole. The report view that folds the transcript to those marks is the `to-human` plugin's; its parser reads this form or the raw tags.
- `compact-instructions.md` is printed by a `PreCompact` hook on every compaction, auto or `/compact`, subagents' included. The harness appends that stdout as "Additional Instructions" after its stock template, which tells the summarizer to follow its structure, so the file says outright that it overrides the template: worded as a suggestion, it was read as a hint and barely moved the summary. The summarizer can call no tools, and the transcript path is appended after the summary.
