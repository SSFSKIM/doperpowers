`★ Insight ─────────────────────────────────────`
- Converting auth checks from inline code to decorators (as this commit does) is a good refactor, but it moves the security decision to a single token at the top of a function — which means a wrong token is now a silent, one-word bug rather than a visibly missing check. Cross-tenant routes are exactly where that costs the most.
- The `save_document` return-value change is a classic "caller contract drift": the function's return type stayed `int`, so nothing — not the type checker, not the interpreter — flagged that its *meaning* changed from a revision number to a row count. Returning a distinct type or a named tuple would have made this a hard error instead of wrong data.
- The off-by-one in pagination is worth noting because it's self-inconsistent within a single response: the payload returns 51 items while the adjacent `limit` field says 50, which is the kind of internal contradiction that makes a good test assertion.
