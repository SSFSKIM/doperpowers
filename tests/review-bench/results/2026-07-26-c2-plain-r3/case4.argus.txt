`★ Insight ─────────────────────────────────────`
- **Format changes need both ends in one commit.** The manifest is an implicit contract between `snapshot.sh` (writer) and `prune.sh` (reader). Shell's `read -r a b c` silently absorbs all extra fields into the last variable rather than erroring, so a widened record produces no crash — just a reader that quietly stops matching reality. That silence is exactly why the retention failure would only surface as disks filling weeks later.
- **`[ "$x" ]` in POSIX shell tests string emptiness, not truthiness.** `"0"` is a one-character string, so the test passes. Numeric-flag comparisons need an explicit `[ "$x" -ne 0 ]` or `[ "$x" != 0 ]`.
- **`trap ... EXIT` is the only reliable cleanup under `set -e`.** A cleanup line placed on the success path runs only when nothing goes wrong, which is precisely the case where cleanup matters least.
