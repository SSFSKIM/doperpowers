- [P2] Reject non-finite constants in numeric validation — /private/var/folders/c1/l4z5k02n2779byvnymzxsvth0000gn/T/review-bench.jwRaED/records.py:52-54
  When input contains `NaN` or `Infinity`, Python's `json.loads` accepts these non-standard constants and this type check treats them as JSON numbers.
